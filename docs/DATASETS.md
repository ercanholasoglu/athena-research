# Datasets

Generated by `python tools/make_index.py` from `tools/datasets.py` and the freeze records. Raw data is **not** redistributed: `python tools/prepare_data.py` downloads each file from its public source into the cache layout the frozen loaders read (`~/.cache/athena-decision-corpus-v2/`, `~/.cache/athena-research-ablation/raw/`) and then runs `tools/verify_data.py`, which recomputes every frozen hash with the frozen functions.

Status per dataset is MATCH, SOURCE_CHANGED (the current source no longer reproduces the frozen frame; reported, never hidden), MISSING or GENERATED (synthetic, built by `common/data.py` from a fixed seed). Preparation, capping and the split rule are code, not prose: `harness/rs2610/common/data.py` (loading, target, row cap, column selection) and `harness/rs2610/common/prep.py` (`holdout_split`: 75/25, time-based for `bike_sharing` and `card_fraud_synth`, group-based where the truth names a group column, stratified otherwise; fixed seed). Rows above the cap are reduced by a seeded random sample before anything else; `rows` below is the frame after capping, which is what the frame hash covers.

Split index hashes were first frozen in the A2/B2 record, so they are listed for the A2/B2 datasets only. For the other datasets the split is a deterministic function of the frozen frame (`holdout_split`, fixed seed), so the frame hash also fixes the split. Study A's evidence packets (`artifacts/study_a/evidence/`) record the measured quantities the contracts quote.

B2 additionally freezes the B2 base frame and truth (`b2_frame_sha256`, `b2_truth_sha256` in [`data/manifest.json`](../data/manifest.json)) and the SHA-256 of every rendered analysis prompt, invention prompt and candidate list for all 10 cells (`b2_prompts.rendered` in the freeze record).
