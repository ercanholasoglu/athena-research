# Study A2: reasoning topology with a frontier model

Frozen on 2026-10-29. Amendment 1 moved the OpenAI arm to `gpt-6-luna` before any Luna run. There is no Anthropic
arm in A2 (amendment 2). Full report:
[FRONTIER_REPLICATION_REPORT.md](../../../harness/rs2610/FRONTIER_REPLICATION_REPORT.md), sections 1–6 and 8–11.
Pre-registration: [PREREGISTRATION.md](../../../harness/rs2610/replication/PREREGISTRATION.md).

## Design

- **What was reused.** The frozen Study A topologies, prompts, contracts and scoring, unchanged.
- **Runs.** {{r.design.a2.instances|int}} unseen instances from {{r.design.a2.datasets|int}} datasets × 4 modes ×
  3 replicates.
- **Hosted arm.** `gpt-6-luna`: {{r.design.a2.LUNA.runs|int}} runs, {{r.design.a2.LUNA.calls|int}} calls,
  ${{r.cost.a2.LUNA.usd|4}} at published prices.
- **Baseline.** The frozen Study A unseen runs of `qwen2.5:7b` on the same instances.
- **Prompts.** The hosted model receives the same frozen prompts. A run's first call is byte-identical to the
  baseline's; later ToT and GoT calls use the same system prompt, stage and token cap and embed the model's own
  earlier outputs. `tools/export_prompts.py` checks this when it replays both ledgers.
- **Request shape.** The provider request is set in
  [`replication/providers.py`](../../../harness/rs2610/replication/providers.py). The schema after strict-mode
  adaptation is in [providers/](providers/). Reasoning settings are in [docs/MODELS.md](../../../docs/MODELS.md).

## Limitations

- **Hidden reasoning.** A hosted DIRECT call already includes provider-side reasoning, so A2 compares orchestration,
  not reasoning against no reasoning.
- **Sampling.** Hosted sampling cannot be seeded.
- **Tier.** One mid-tier hosted model; nothing about either provider's top tier.
- More: [docs/LIMITATIONS.md](../../../docs/LIMITATIONS.md).
